PROJECT: PHISHING AWARENESS SIMULATION
TOOL: CYBERSAFE LOCAL TRAINING LAB

REQUIREMENTS:
1. Windows 10/11
2. Python 3.9 or newer
3. Web browser

INSTALLATION:
1. Extract the project folder.
2. Open the project folder.
3. Click the address bar in File Explorer.
4. Type CMD and press Enter.
5. Run:

   python app.py

RUNNING:
Open your browser:

http://127.0.0.1:8080

PROJECT FEATURES:
1. Simulated phishing email preview.
2. Harmless login demonstration.
3. Click tracking.
4. Demo form attempt tracking.
5. Campaign statistics dashboard.
6. Local SQLite database.

SECURITY:
No actual emails are sent.
No passwords are stored.
No external participants are contacted.
All data remains in the local project database.

STOP:
Press CTRL+C in CMD.
